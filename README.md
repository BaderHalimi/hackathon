# هاكاثون السايبر والذكاء الاصطناعي 2026

الموقع الرسمي للهاكاثون — **النادي الهندسي، لجنة الأنشطة، هندسة الحاسوب**، الكلية الجامعية للعلوم التطبيقية، غزة — بالشراكة مع **حاضنة يوكاس التكنولوجية**.

- الاسم العربي: هاكاثون السايبر والذكاء الاصطناعي 2026
- الاسم الإنجليزي: AI & Cyber Hackathon 2026
- المقر: المقر الرئيسي — غزة
- مدة الفعالية الميدانية: 6 ساعات
- تكوين الفريق: 2 طلبة أمن سيبراني + 2 طلبة ذكاء اصطناعي

الهوية البصرية (من ملف الهوية الرسمي): `#F1791E` الأساسي، `#2A3876` الداكن، `#66AC2F` الثانوي.

---

## تشغيل المشروع

```bash
composer install
npm install

cp .env.example .env          # إذا ما في ملف .env
php artisan key:generate

php artisan migrate           # ينشئ جداول التسجيلات وإعدادات الصفحة
php artisan storage:link      # ضروري لصور اللوحة المرفوعة

php artisan serve             # http://127.0.0.1:8000
```

لإنشاء مستخدم لوحة الإدارة:

```bash
php artisan make:filament-user
```

لوحة الإدارة على `/admin`.

### ملاحظات نشر مهمة

- **`APP_URL` يجب أن يكون الدومين الحقيقي** (مثال: `https://hackathon.ucaseng.club`)، لأن روابط الصور المرفوعة و`og:image` تُبنى من هذا المتغير.
- نفّذ `php artisan storage:link` على السيرفر مرة واحدة، وإلا لن تظهر الصور المرفوعة من اللوحة.
- نفّذ `php artisan migrate` بعد كل تحديث يجلب مايقريشن جديد.

## لوحة الإدارة

كل محتوى الصفحة الرئيسية يُدار من `/admin` تحت مجموعة **محتوى الصفحة الرئيسية**. الأقسام:

| القسم | ماذا يتحكم |
| --- | --- |
| الهوية والتنقل | عنوان الصفحة، وصفها، اسم الحدث، الموقع، بيانات التواصل، روابط السوشال، تسميات القائمة |
| **المظهر والألوان** | وضع الصفحة (فاتح/داكن)، الألوان الأساسية، نسبة توزيع اللونين، الخلفية المتحركة |
| **الأيقونة** | شعار الموقع (نسخة فاتحة + نسخة داكنة)، أيقونة المتصفح، صورة المشاركة على السوشيال ميديا |
| **شعارات الجهتين** (داخل تبويب الهوية والتنقل) | شعار النادي الهندسي وشعار حاضنة يوكاس — نسخة فاتحة ونسخة داكنة لكل واحد |
| واجهة الصفحة | العنوان الرئيسي، الوصف، الأزرار، موعد الإغلاق، عبارات الشريط المتحرك |
| الشركاء وعن الهاكاثون | عبارة الشركاء، بطاقات التعريف، برنامج الساعات الست |
| المسارات | مسارات التحدي والمزايا المختصرة |
| الجدول الزمني | المراحل والرسائل الجانبية |
| الجوائز والشروط | المراكز والجوائز، ومزايا إضافية، شروط الأهلية وقواعد الحدث |
| الأسئلة الشائعة | الأسئلة والأجوبة |
| نموذج التسجيل | كل نصوص النموذج والحقول وخيارات القوائم ورسائل التحقق |
| التذييل | وصف الجهة، عناوين الأعمدة، حقوق النشر |

### المظهر والألوان

- **وضع الألوان**: `فاتح` أو `داكن`. الوضع الفاتح هو الافتراضي، والداكن يستخدم نفس ألوان الهوية على خلفية غامقة.
- **اللون الأساسي (Primary)**: الأزرار الرئيسية والعناوين المميزة. الافتراضي `#F1791E`.
- **اللون الثانوي (Secondary)**: الشارات وعلامات الصح والتأكيدات. الافتراضي `#66AC2F`.
- **اللون الداكن (Base)**: النصوص والعناوين والأسطح الداكنة (التذييل والشريط العلوي وكتلة الطرفية). الافتراضي `#2A3876`.
- **نسبة اللون الأساسي مقابل الثانوي**: 0% = اللون الثانوي فقط، 50% = مناصفة، 100% = اللون الأساسي فقط. تتحكم بمقدار ظهور كل لون في التدرّجات اللونية على الصفحة.
- **تشغيل الخلفية المتحركة**: إيقافها يجعل الخلفية لونًا صافيًا بدون حركة.

كل مشتقات الألوان (الفاتحة والغامقة والحدود والظلال وألوان خلفية الحروف المتحركة) تُحسب تلقائيًا من الألوان الثلاثة، فما في حاجة لتعديل أي كود عند تغييرها.

### الأيقونة

أربعة حقول رفع صور تُخزَّن في `storage/app/public/branding`:

- **شعار الموقع — الوضع الفاتح**: يظهر في الهيدر والتذييل بالوضع الفاتح.
- **شعار الموقع — الوضع الداكن**: يظهر في الهيدر والتذييل بالوضع الداكن. لو تركته فارغًا يُستخدم شعار الوضع الفاتح.
- **أيقونة الموقع (Favicon)**: الأيقونة في تبويب المتصفح (مربّعة يُفضّل).
- **صورة المشاركة على السوشيال ميديا**: تظهر عند مشاركة الرابط، المقاس المفضّل 1200×630. لو تركتها فارغة يُستخدم شعار الموقع.

### شعارات الجهتين

داخل نفس التبويب (الهوية والتنقل) قسم مخصّص لشعار الجهتين، وفيه أربعة حقول رفع:

- **شعار النادي الهندسي — الوضع الفاتح** و**الوضع الداكن**
- **شعار حاضنة يوكاس — الوضع الفاتح** و**الوضع الداكن**

الشعاران يظهران في **قسم الشركاء** بالصفحة الرئيسية وبنُسخة صغيرة في **التذييل**. لو رفعت نسخة واحدة فقط تُستخدم في الوضعين، ولو ما رفعت أي نسخة يظهر مكان الشعار الفاضي (الإطار المتقطّع) مكانه.

خلفية إطار الشعار تتبع وضع الصفحة تلقائيًا (فاتحة مع الوضع الفاتح وشفافة فاتحة مع الداكن)، لذلك يُفضّل استخدام شعار بخلفية شفافة.

## شعارات الجهتين (النادي الهندسي وحاضنة يوكاس)

الطريقة الأساسية: ارفع الشعارين من لوحة الإدارة — **الهوية والتنقل ← شعارات الجهتين** (نسخة فاتحة ونسخة داكنة لكل شعار).

الطريقة البديلة: ضع الملفين بهذين المسارين، وتُستخدم تلقائيًا كقيمة افتراضية عند عدم رفع أي شعار من اللوحة:

```
public/images/eng-club.png     ← شعار النادي الهندسي
public/images/ucas.png         ← شعار حاضنة يوكاس التكنولوجية
```

في الحالتين يختفي النص البديل ("مكان شعار...") ويظهر الشعار تلقائيًا في الموضعين، بدون أي تعديل برمجي. لو أردت مسارًا أو اسمًا مختلفًا، عدّل وسم `<img src="...">` في `resources/views/home.blade.php`.

نصوص الشعار البديلة ووصفها تُعدَّل من: **الهوية والتنقل ← النصوص البديلة وإمكانية الوصول**.

## هيكلة الملفات المهمة

```
resources/views/home.blade.php              الصفحة الرئيسية (HTML + CSS + JS)
config/home-content.php                     المحتوى الافتراضي لكل قسم + مفاتيح الإعدادات
app/Support/HomeContent.php                 قراءة/حفظ إعدادات الأقسام (مع كاش)
app/Http/Controllers/HomeController.php     يحمّل كل الأقسام ويمرّرها للصفحة
app/Http/Controllers/RegistrationController.php   استقبال طلبات التسجيل والتحقق منها
app/Models/Registration.php                 موديل التسجيلات
app/Models/HomeSection.php                  موديل إعدادات الأقسام
app/Filament/Pages/*.php                    صفحات لوحة الإدارة (قسم لكل صفحة)
app/Filament/Pages/Concerns/EditsHomeSection.php   الحقول المشتركة لكل الأقسام
config/hackathon.php                        الإعدادات القديمة (موعد الإغلاق، واتساب، الحد الأعلى للفريق)
```

### التسجيلات

طلبات التسجيل تُخزَّن في جدول `registrations` (الحقول: رقم مرجعي، نوع المشاركة، بيانات مقدّم الطلب، بيانات الفريق، الفكرة، بيانات تقنية).

لعرض الطلبات:

```bash
php artisan tinker
>>> App\Models\Registration::latest()->get();
```

لمنع تكرار التسجيل بنفس البريد الإلكتروني: مضمّن في `RegistrationController`. كذلك فيه `throttle:12,1` على مسار الإرسال، ومنع للتقديم بعد انتهاء الموعد.

## أمور تحتاج تأكيدك

1. **تاريخ الفعالية** غير محدّد بعد في ملف الهوية، لذلك يظهر "يُعلن لاحقًا" في الصفحة. عدّله من: واجهة الصفحة ← تواريخ الحدث.
2. **موعد إغلاق التسجيل** الحالي `2026-10-29 23:59` كقيمة مبدئية — يُعدّل من: واجهة الصفحة ← موعد الإغلاق (بصيغة ISO مع المنطقة الزمنية).
3. **قيم الجوائز** (‏$3,000 / $1,500 / $750) مبدئية — تُعدّل من قسم الجوائز والشروط.
4. **تعارض في الاسم الإنجليزي**: ملف الهوية يقول `AI & Cyber Hackathon 2026`، وشعار `CA` يقول `CYBER & AI HACKATHON 2026`. الصفحة حاليًا تتبع ملف الهوية (لأنه المرجع الرسمي للأسماء). لتغييره: الهوية والتنقل ← الاسم بالإنجليزية. نفس الملاحظة على الاسم العربي: "هاكاثون السايبر والذكاء الاصطناعي" حسب الملف مقابل "هاكاثون الأمن السيبراني..." على الشعار.
5. **رقم واتساب** فارغ، لذلك زر "إرسال نسخة على واتساب" مخفي في نافذة نجاح التسجيل. لتعبئته: `HACKATHON_WHATSAPP` في `.env` بصيغة دولية بدون `+`.

## الفحوصات التي تمت

- الصفحة تستجيب `200` وتُبنى بالوضعين الفاتح والداكن.
- تسجيل فردي وتسجيل فريق (4 أعضاء بتكوين 2+2) يُخزَّنان في قاعدة البيانات، مع أرقام مرجعية فريدة.
- رسائل التحقق بالعربية (422) ومنع تكرار البريد الإلكتروني.
- حفظ إعدادات المظهر والألوان من لوحة الإدارة ينعكس على الصفحة فورًا (الوضع + الألوان + النسبة).
- حقول رفع الشعارات (شعار الموقع + شعارا الجهتين) بنسختَي فاتح/داكن تعمل، وكل وضع يعرض نسخته، ويُستخدم الملف الافتراضي عند عدم الرفع.
- الشريط العلوي بلون مناسب في الوضعين (86% داكن / 88% فاتح) مع تمييز واضح للنصوص.
